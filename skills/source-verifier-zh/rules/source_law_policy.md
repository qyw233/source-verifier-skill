# 法律与政策信息特殊规则

法律、法规、政策和监管问题必须优先使用原始文本。

## 最佳来源

```text
法律条文
法规原文
政府官网
监管机构公告
法院判决
官方 FAQ
正式征求意见稿
标准文本
```

## 二级来源

```text
律师事务所解读
新闻报道
政策评论
专家文章
智库分析
```

二级来源适合解释背景，但不能替代官方原文。

## 必须检查

```text
司法辖区
生效日期
修订日期
是否仍然有效
是否只是草案
是否只是征求意见稿
是否有过渡期
是否有例外条款
```

## 常见误判

```text
草案 ≠ 已生效法律
媒体解读 ≠ 法律条文
地方政策 ≠ 全国政策
旧法规 ≠ 当前有效法规
处罚案例 ≠ 普遍规则
```

## 安全提示

如果用户需要个人法律决策，应说明这不是正式法律意见，需要咨询专业律师或当地主管机构。
