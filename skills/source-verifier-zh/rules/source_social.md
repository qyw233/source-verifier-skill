# 社交平台来源处理规则

社交平台来源的证据强度高度依赖于**账号主体的身份与可信度**。不能仅凭"社交平台"这一载体本身做统一判断，必须逐账号评估其主体身份、认证质量、专业领域匹配度、立场倾向和利益关系。

## 一、核心原则：以账号主体身份为评估核心

社交平台是载体，不是内容生产者。同一平台上的不同账号，其可信度可天差地别。评估社交平台来源时，核心问题是：

```text
这个账号是谁在运营？
这个人的身份与用户提问的领域有什么关系？
这个人的认证是什么性质？
这个人的立场和潜在利益关系是什么？
```

## 二、账号主体身份分级

首先将社交平台账号主体分为两大类：**有影响力主体或利益相关方**（A1 公众人物 / A2 意见领袖 / B 机构）和**普通民众**。前者包括具有广泛影响力的人物，也包括与用户提问话题存在直接利益关联的当事方（即使其本身影响力有限）。

### 2.1 有影响力主体或利益相关方

需要更加仔细地甄别和斟酌，不能完全接受其言论。利益相关方指与用户提问话题存在直接利害关系的主体——即使其社会影响力有限，但因身处事件之中，其言论具有特殊的证据价值或偏倚风险。

#### A 类：自然人——公众人物

包括明星、名人、政要、知名企业家、行业领袖等因其身份或职务而具有广泛社会影响力的个人。

```text
典型对象：演艺明星、体育明星、知名企业家（如 Elon Musk、雷军）、
          政要（总统/首相/部长/议员等）、国际组织负责人、
          具有行业话语权的知名专家
```

##### 评估要点

1. **认证质量**：该账号是否有高质量认证？
2. **言论与用户提问的关系**：该公众人物在此话题上是否为直接当事人、权威发言人、或仅是个人意见？
3. **立场分析**（详见第三节）
4. **利益关系检测**（详见第四节）

##### 认证质量评估

并非所有认证都具有同等的参考价值。必须区分：

**高质量认证**（较难申请、有门槛）：

```text
政府/机构官员认证（如微博"政务""蓝V机构号"、LinkedIn 经机构邮箱验证的工作身份）
行业资质认证（如微博"医生""律师"认证，需提交执业证书审核）
官方身份认证（如 Twitter 政府官员灰色标签、机构金标/灰标）
平台邀请制的权威身份认证（非开放申请的认证类型）
```

**低质量认证**（仅需付费或门槛极低）：

```text
X（Twitter）Blue / Premium 付费会员认证 —— 任何付费用户均可获得蓝色勾号
微博"会员认证"—— 付费即可
大部分平台的"已认证"标记如仅需手机号或简单信息验证
```

**认证范围与言论领域的对应关系**：

```text
认证范围与言论相关 → 认证对该言论有一定支撑作用
  例：金融从业者认证 + 金融类言论 → 具有一定专业参考价值
  例：医生认证 + 医疗健康言论 → 具有一定专业参考价值

认证范围与言论无关 → 认证对该言论没有特别支撑作用
  例：金融从业者认证 + 医疗健康言论 → 认证不提供额外权威
  例：娱乐明星认证 + 科技产品技术评价 → 认证不提供额外权威

无认证但过往言论表现出专业背景 → 仍可合理考虑其意见
  例：某行业从业者未认证，但长期发布该领域专业内容且被同行认可
```

##### 公众人物的可用性判断

```text
公众人物作为事件的直接当事人/发言人 → 可视为一手来源
  例：某公司 CEO 在社交平台亲自宣布公司重大决策
  → citation_usability 可达 highly_usable 或 usable（需标注为"当事人直接表态"）

公众人物对非专业领域的个人意见 → 仅作一般参考
  例：某娱乐明星对政治事件的评论
  → citation_usability: use_with_caution

公众人物在自身专业领域发表意见且认证匹配 → 可谨慎参考
  例：执业律师（认证）评论法律事件
  → citation_usability: usable（需交叉验证）
```

#### A2 类：意见领袖 / KOL / 大V / 网红 【重点考察】

**意见领袖是社交平台上需要特别关注和着重考量的一类主体。** 与 A 类公众人物不同，意见领袖通常不是因其身份职务而获得影响力，而是通过持续在社交平台上发声、积累大量粉丝而获得较强话语权的个人。

```text
典型对象：各平台上的大V、网红博主、知名UP主、头部主播、
          高粉丝量的垂直领域KOL（科技/财经/美妆/汽车/游戏/教育等）、
          自媒体头部账号的运营者（即使其内容被归为自媒体，但作为个人仍属于意见领袖范畴）
```

##### 意见领袖的核心特征

```text
1. 粉丝量级显著（通常十万级及以上），拥有较强的话语权和传播力
2. 依靠个人观点、内容产出或人设吸引粉丝，而非机构身份
3. 对粉丝群体具有明显的舆论引导能力
4. 可能存在多种变现方式和商业合作关系
5. 通常具有较为明确和坚定的个人立场与偏好
```

##### 意见领袖的特殊评估维度

意见领袖的评估不能仅套用公众人物的通用标准，必须从以下维度进行着重分析：

**（一）话语权与影响力评估**

```text
粉丝数量（万级/十万级/百万级/千万级）
  → 粉丝越多，其言论的传播影响力越大，评估责任也应越严格
  → 需注意：粉丝数可能是购买的虚假粉丝，应结合互动率（点赞/评论/转发量相对于粉丝数的比例）综合判断

内容传播力
  → 单条内容的平均互动量
  → 内容被其他账号引用/转发的频率
  → 是否在特定话题上具有议程设置能力

受众粘性
  → 评论区是否为有质量的讨论 vs 粉丝刷赞/控评
  → 粉丝对该意见领袖的信任度和追随程度
```

**（二）立场与偏好识别 【必须着重标记】**

意见领袖通常具有较为坚定的个人立场和偏好，这些立场可能深刻影响其言论的客观性和公正性：

```text
品牌/产品偏好：
  例：某科技KOL长期偏好某品牌手机，对其竞争对手产品一贯贬低
  例：某美妆博主习惯于推荐特定品牌，从不客观评价竞品
  → 需标记品牌偏好方向

商业合作倾向：
  例：与某公司/品牌有长期合作关系
  例：投资或持股某企业，在相关话题上可能偏袒
  → 需标记潜在商业关联

政治/价值观立场：
  例：对国家政策、国际关系等有明确站队
  例：对特定社会议题（环保、女权、隐私、开源等）有坚定表态
  → 需标记政治或价值观立场倾向

对某事物/事件的偏好或厌恶：
  例：某KOL公开表达过对某技术的"信仰"或"排斥"
  例：某网红对某类产品有个人偏好（如"只推国货""绝不推荐XX品牌"）
  → 需标记具体偏好/厌恶对象

行业站队：
  例：在行业争议中明确站在某一方
  例：长期攻击某种商业模式或技术路线
  → 需标记行业立场
```

**（三）商业利益与变现关系检测 【必须着重考量】**

意见领袖通常依赖社交平台进行商业变现，其言论中的商业动机必须被严格审查：

```text
广告/赞助关系：
  - 是否标注了广告或赞助？
  - 是否有长期合作的品牌方？
  - 推荐产品时是否提供了购买链接/优惠码？
  → 若涉及推荐类内容，默认假设存在商业动机，除非有明确证据表明为纯客观评测

利益绑定：
  - 是否在推荐的公司/品牌中持有股份或经济利益？
  - 是否为其推荐产品的生产商/经销商？
  - 是否与被批评的对象存在竞争关系？
  → 利益绑定比一般赞助的影响更深远，需要更严格的降权处理

平台激励：
  - 是否受平台流量激励政策驱动（如蹭热点、标题党）？
  - 是否参与平台的广告分成或电商分成计划？
  → 平台激励可能驱动意见领袖追求流量而非准确性

变现模式分析：
  - 广告收入 → 倾向于产出更多吸引眼球的内容
  - 带货/电商 → 推荐的产品可能不是最优而是佣金最高的
  - 知识付费 → 可能夸大问题的严重性以促进课程销售
  - 粉丝打赏 → 倾向于迎合粉丝群体的既有观点
  → 不同变现模式会产生不同类型的偏倚
```

**（四）意见领袖言论的可用性判断**

```text
意见领袖作为事件的直接当事人 → 可视为一手来源
  → citation_usability: usable（标注为"意见领袖当事人表态"）

意见领袖在其深耕的垂直领域发表专业意见：
  → 若：有可查证的专业背景 + 无商业利益关联 + 引用原始来源
    → citation_usability: usable（需交叉验证）
  → 若：缺乏可查证背景 或 存在商业利益关联
    → citation_usability: use_with_caution（标注利益关系）

意见领袖对非专业领域发表意见：
  → citation_usability: use_with_caution 或 not_recommended

意见领袖发表明显带有品牌偏好/商业倾向的言论：
  → 必须标注具体的偏倚方向
  → citation_usability 降一级
  → 如果为未标注的商业推广 → not_recommended 或 do_not_use

意见领袖发表煽动性、情绪化或明显以流量为目的的言论：
  → citation_usability: not_recommended 或 do_not_use
  → 在 warnings 中注明"言论具有明显的情绪煽动/流量导向特征"
```

**（五）多个意见领袖说法一致的特殊处理**

```text
必须特别警惕多个意见领袖在同一话题上说法一致的情况：

1. 检查这些意见领袖是否存在共同的商业关联（同一MCN、同一品牌合作等）
2. 检查说法是否源自同一信息源（可能仅仅是相互转发/引用）
3. 检查发布时间是否高度集中（可能是组织的营销活动或舆论操控）
4. 分析是否有人首先发声，其他人跟风（"羊群效应"）

结论：
  - 如果存在共同商业关联或同源 → 不视为多方独立验证
  - 即使无明显关联，多个意见领袖一致也只应视为"舆论倾向"，而非"事实确认"
  - 必须追溯到官方或权威一手来源进行最终验证
```

##### 意见领袖的输出标记要求

对于意见领袖来源，必须在输出中增加以下标记：

```text
secondary_tags 必须添加：
  opinion_leader  —— 标识该主体为意见领袖
  + 具体偏倚标签（按实际情况）：
    - brand_preference_detected（品牌偏好）
    - commercial_collaboration_detected（商业合作）
    - value_stance_detected（价值观立场）
    - industry_side_detected（行业站队）

warnings 必须包含：
  - "该来源为拥有XX万粉丝的意见领袖，具有较强话语权和传播影响力"
  - "该意见领袖在[相关话题/品牌/领域]上存在[具体立场/偏好/利益关系]"
  - "其言论可能受[商业合作/个人偏好/平台激励]因素影响"

recommended_action:
  - "建议寻找无利益关联的独立来源进行交叉验证"
  - "建议确认该言论是否为广告/赞助内容"
```

##### 意见领袖与公众人物、自媒体的区分

```text
公众人物（A1）vs 意见领袖（A2）：
  公众人物：影响力来源于其身份/职务（明星、政要、企业家）
  意见领袖：影响力来源于其在社交平台上的持续内容产出和粉丝积累
  两者可能有重叠（如果某明星同时也是活跃的内容创作者）

意见领袖（A2）vs 自媒体（self_media）：
  → 从账号运营性质区分：如果其账号属于自媒体（商业变现 + 个人IP运营），
    则来源类型应路由至 self_media，按 rules/source_self_media.md 评估
  → 从个人身份区分：如果作为个人在社交平台发布言论（而非通过其自媒体渠道），
    且具有显著的意见领袖特征，则在此作为 A2 类意见领袖评估
  → 简单判断：看具体来源 URL 是其自媒体内容还是其社交账号的帖子
```

#### B 类：机构/组织账号

包括公司、政府机构、非营利组织、学校、媒体机构等在社交平台上的官方账号。机构账号通常属于利益相关方——其对自身相关事务的发言具有一手证据价值，但在涉及自身利益的议题上也可能存在自利动机。

##### B-1：公司/企业官方账号

```text
用于确认官方信息（如产品发布、公告、回应） → 高可用性
用于讨论行业趋势 → 需注意其商业立场和潜在自利动机
```

##### B-2：政府/监管机构官方账号

```text
用于确认政策、法规、官方表态 → 高可用性
注意：即使是官方账号，政治性表态仍需结合政治立场分析
```

##### B-3：权威媒体机构在社交平台上的账号

**这是需要特别处理的子类型。** 权威媒体（如新华社、BBC、Reuters、NYT 等）在社交平台上发布的内容，根据其是否引用自家媒体来源，做不同处理：

```text
情况一：该帖子/推文引用了自家媒体的完整报道（含链接）
  → 该社交平台内容与自家媒体信源保持一致
  → 参照 rules/source_news.md 对该媒体的评估规则
  → 社交平台帖子仅视为该媒体报道的"入口"
  → citation_usability 与原始报道一致

情况二：该帖子/推文未引用自家媒体报道，为独立编辑发布的内容
  → 视为该媒体账号在进行类似自媒体的运营
  → 缺乏完整的编辑审核流程（社交平台快节奏发布，审核标准低于正式报道）
  → 参照 rules/source_self_media.md 规则进行评估
  → 默认 citation_usability 不超过 use_with_caution
  → 必须添加 secondary_tags: ["social_media_standalone_post"]

情况三：该帖子/推文为引用/转发其他来源（非自家）
  → 应追溯到原始来源
  → 该帖子本身仅作为传播节点，不具备独立证据价值
```

##### B-4：权威机构关键人物的个人账号

包括公司高管、政府官员、机构发言人等在社交平台上的个人或工作账号。

```text
这些关键人物通常拥有高质量认证（较难申请、有门槛）

可用场景：
  - 作为该机构的非正式表态或补充信息
  - 了解该机构的立场方向或内部视角
  - 当事人直接确认或否认某事件

注意事项：
  - 个人账号言论不等于机构官方立场（除非明确以机构身份发言）
  - 即使是关键人物，其个人账号也可能包含个人偏见
  - 应标注为"机构关键人物的个人表态"
  - citation_usability 默认不超过 usable
  - 如果多个关键人物说法一致 → 可信度可适当提升但仍需官方确认
```

##### B-5：不知名员工账号

部分员工可能没有认证，但其过往言论表现出其从事相关行业、具有专业背景。

```text
识别信号：
  - 账号简介提及所在公司/机构
  - 历史内容围绕特定行业展开
  - 发布过可验证的专业信息（如内部截图需谨慎对待）
  - 被同事或同行互动、认可

评估要点：
  - 该员工的言论是否在其日常工作范围内？
    → 若在范围内（如工程师讨论公司技术）→ 有一定参考价值
    → 若明显超出范围（如基层员工谈论公司战略）→ 参考价值较低
  - 是否涉及内部机密或未公开信息？
    → 若涉及 → 谨慎对待，可能违反保密协议，且无法验证
  - citation_usability 默认不超过 use_with_caution
```

### 2.2 普通民众

一般个人用户的社交账号，无显著影响力、无专业认证、无机构归属。

```text
评估原则：
  - 一般作为参考意见，不宜作为关键证据
  - 可用于了解公共反应、用户体验、民间观点
  - 多个普通用户说法一致时，可能反映某种舆论倾向，但不能作为事实确认

可用场景：
  - 产品/服务的用户体验案例
  - 舆情分析、公共反应调研
  - 线索发现（需进一步验证）

不可作为：
  - 事实确认的唯一来源
  - 科学/医学/法律结论的依据
  - 公司/机构官方立场的替代

默认 citation_usability: use_with_caution 或 not_recommended
```

## 三、立场倾向分析

在社交平台上活跃的公众人物和机构，通常具有较为坚定的立场倾向。这些立场可能显著影响其言论的客观性，是评估时必须考虑的因素。

### 3.1 需要识别的立场类型

```text
政治立场：
  例：政治人物的党派立场、对国家政策的支持/反对态度
  例：在涉及国际关系话题时的国家立场倾向
  → 需标注 political_leaning

商业立场：
  例：某投资人/企业家对某行业的偏好或排斥
  例：某公司高管对竞争对手的评价
  → 需标注 commercial_leaning

偏好/价值观立场：
  例：对特定技术路线的偏好（如某 AI 研究者力挺某种架构）
  例：对社会议题的特定立场（环保、隐私、开源等）
  → 需标注 preference_leaning
```

### 3.2 立场分析流程

```text
1. 识别该账号在用户提问相关话题上的历史表态
2. 判断立场是公开坚定还是模糊多变
3. 评估该立场是否影响其当前言论的客观性：
   - 直接利益相关方 → 高偏倚风险
   - 长期公开站队某方 → 中偏倚风险
   - 无明显过往立场 → 低偏倚风险（仍需关注其他信号）
4. 在报告中输出立场标签和影响评估
```

### 3.3 输出建议

```text
对于有明确立场的来源，在 secondary_tags 中添加立场标签：
  political_bias_detected
  commercial_bias_detected
  preference_bias_detected

在 warnings 中注明：
  "该账号在此话题上有明确的[政治/商业/偏好]立场，可能影响言论客观性"
```

## 四、利益关系与广告嫌疑检测

有影响力的公众人物和机构在社交平台上的发言，可能存在隐藏的商业利益。需要参照自媒体规则（`rules/source_self_media.md`）中的相关做法进行检测。

### 4.1 检测信号

```text
明确广告/赞助信号：
  - 帖子标注 #ad #sponsored #合作 或类似标签
  - 明确提及某品牌/产品并配合购买链接/优惠码
  - 内容为产品推广且风格与其他内容明显不同

疑似广告/宣传信号：
  - 对某产品/品牌/公司一致好评，从不提及缺点
  - 发布频率异常，在特定时间集中推广
  - 与商业伙伴互动频繁，互相推广
  - 内容与账号常规话题领域偏离，异常推荐特定产品
  - 使用营销话术（"亲测有效""必须入手""强烈推荐"等无客观支撑的表述）

利益相关信号（非广告但存在利益关系）：
  - 讨论对象为账号持有者投资/持股的公司
  - 讨论对象为账号持有者所在公司或直接竞品
  - 讨论对象为账号持有者的合作伙伴或商业关联方
  - 账号持有者在相关话题上有直接经济利害关系
```

### 4.2 处理方式

```text
确认广告/赞助且未标注 → 严重问题
  → secondary_tags: ["undisclosed_advertisement"]
  → citation_usability: not_recommended 或 do_not_use
  → warnings 添加："内容疑似为未标注的商业推广，客观性存疑"

明确标注广告/赞助 → 透明度合格但可信度受限
  → secondary_tags: ["disclosed_advertisement"]
  → citation_usability: use_with_caution（标注为"已声明赞助内容"）

存在利益关系但非直接广告 → 需标注
  → secondary_tags: ["potential_conflict_of_interest"]
  → citation_usability 降一级
  → warnings 添加："账号持有者与该话题存在潜在利益关系"

无明显利益关系 → 不影响评分
```

### 4.3 利益关系重要性评估

并非所有利益关系都会严重影响可信度。需要评估利益关系的**直接程度**和**影响力度**：

```text
核心利益关系（严重影响客观性）：
  例：某 CEO 评价自家公司产品
  例：某投资人评价其投资组合中的公司
  → 默认视为立场声明，而非客观分析

间接利益关系（可能影响但非决定性）：
  例：某行业从业者评价同行
  例：某公司员工评价所在行业趋势
  → 需标注但不完全否定

无利益关系：
  例：消费者评价与自身无任何商业关联的产品
  → 正常评估
```

## 五、社交平台来源的可用场景总览

### 可较强使用的情况

```text
账号属于原始公司/政府机构/项目团队 → 加标签 official_social
账号属于事件当事人/直接发言人 → 加标签 primary_source  
账号通过高质量认证且言论在专业领域范围内
权威媒体账号引用了自家媒体的完整报道（含链接）
帖子包含原始文件、公告、代码、图片或视频且可验证
帖子链接到官方来源且内容一致
发布时间明确、上下文完整
```

这类来源可标记为：

```text
social_media + official_social（或其他相应次级标签）
citation_usability: highly_usable 或 usable
```

### 需谨慎使用的情况

```text
有影响力的公众人物在非专业领域的言论
高质量认证但与发言领域不匹配
低质量认证（付费认证）
机构关键人物的个人账号表态（非官方渠道）
不知名员工但历史内容显示有行业背景
无认证但具可查证专业背景的账号
权威媒体账号未引用自家报道的独立社交平台内容
```

```text
citation_usability 默认不超过 use_with_caution
必须结合立场分析和利益关系检测综合判断
```

### 不建议作为最终证据的情况

```text
匿名账号
无认证且无法查证背景的账号
普通民众对专业领域话题的单一说法
截图（参照第六节截图处理）
转发/搬运（应追溯原始来源）
传言串/评论区内容
无时间戳/无上下文/无原始链接
只表达个人猜测或情绪
存在未标注的商业推广
存在明显利益冲突且未说明
```

## 六、自媒体识别与路由

自媒体（self-media）指个人或小团队在社交/内容平台上以独立创作者身份运营的账号，通常依赖平台流量分成、广告、带货或知识付费变现。自媒体与传统媒体和官方账号的核心区别在于：缺乏机构编辑审核机制，内容质量完全取决于个人能力与动机。

### 自媒体识别信号

出现以下多数信号时，应判断为自媒体：

```text
账号名称带有"XX说""XX观察""XX日记""XX老师""XX哥/姐"等个人 IP 化特征
账号简介强调个人身份而非机构归属（如"前XX公司员工""独立研究者"）
内容以观点、评论、解读为主，而非一手新闻报道或官方公告
主页或内容中带有商业推广、带货链接、课程推广、付费社群引流
内容更新频率极高（日更多条），标题追求点击率
账号未通过机构认证，仅有个人认证或未认证
头像为个人照片或卡通形象，而非机构 logo
内容风格个人化，频繁使用"我""我认为""我觉得"
评论区存在大量粉丝互动而非事实讨论
跨平台同名账号矩阵运营
```

### 路由规则

如果识别为自媒体，必须**立即终止**当前 `source_social.md` 的规则处理，将来源重新分类为 `self_media` 主类型，并切换至 `rules/source_self_media.md`：

```text
source_type: social_media  →  判定为自媒体  →  STOP source_social.md
                                              →  source_type = self_media
                                              →  加载 rules/source_self_media.md
```

自媒体来源默认不高于 `use_with_caution`。

### 自媒体与官方账号 / 有影响力主体及利益相关方的区分

```text
认证机构账号 → official_social → 按本规则 B 类机构账号处理
认证个人专家（如学者、医生、律师实名认证且有机构背书）→ 按本规则 A1 类有影响力人物处理
有影响力的公众人物（名人/明星/政要）→ 按本规则 A1 类有影响力人物处理
意见领袖 / KOL / 大V（高粉丝量、强话语权的内容创作者）→ 按本规则 A2 类意见领袖处理
未认证/个人认证 + 个人IP运营 + 商业变现 → self_media → 加载 source_self_media.md
```

## 七、截图处理

截图默认低可信，应检查：

```text
是否能找到原帖链接
截图是否完整
账号是否真实
时间是否清晰
是否可能被编辑
是否有其他来源印证
```

若无法找到原帖，应标记：

```text
citation_usability: not_recommended
article_quality_score: < 30
```

## 八、输出建议

### 8.1 完整输出格式

```json
{
  "source_type": "social_media",
  "account_holder": {
    "category": "public_figure | opinion_leader | institution | employee | general_public",
    "sub_category": "celebrity | politician | executive | industry_expert | kol_vertical | kol_general | influencer | live_streamer | corporate_official | government_account | media_organization | key_personnel | unknown_employee | ordinary_user | ...",
    "identity_verifiable": true,
    "verification_quality": "high_quality | low_quality | unverified",
    "verification_relevance_to_claim": "matched | unrelated | partial",
    "follower_count_tier": "mega | macro | mid | micro | nano | unknown",
    "professional_domain": "technology | finance | healthcare | law | entertainment | politics | general | unknown"
  },
  "post_type": "original_post | repost | screenshot | comment",
  "is_official_account": false,
  "stance_analysis": {
    "political_leaning_detected": false,
    "commercial_leaning_detected": false,
    "preference_leaning_detected": false,
    "brand_preference_detected": false,
    "commercial_collaboration_detected": false,
    "value_stance_detected": false,
    "industry_side_detected": false,
    "stance_note": "该账号在此话题上有明确的商业立场，可能影响言论客观性"
  },
  "conflict_of_interest": {
    "detected": false,
    "type": "advertisement | sponsorship | financial_interest | undisclosed_ad | none",
    "severity": "high | medium | low | none",
    "note": "账号持有者与讨论对象存在投资关系"
  },
  "citation_usability": "highly_usable | usable | use_with_caution | not_recommended | do_not_use",
  "reasons": [
    "该来源为当事企业 CEO 的认证账号，属一手表态",
    "账号通过高质量机构认证，与言论领域匹配",
    "内容为个人观点，非官方声明"
  ],
  "warnings": [
    "社交平台来源，不宜作为唯一证据",
    "账号持有者在此话题上有明确商业立场",
    "疑似存在未标注的商业推广"
  ],
  "recommended_action": "cross_check_with_official_source"
}
```

### 8.2 简洁输出格式（普通用户场景）

当来源为普通民众或简单社交平台内容时，可用精简格式：

```json
{
  "source_type": "social_media",
  "is_official_account": false,
  "post_type": "original_post | repost | screenshot | comment",
  "citation_usability": "use_with_caution",
  "warnings": ["社交平台来源，不宜作为最终证据"]
}
```

### 8.3 字段说明

| 字段 | 说明 |
|------|------|
| `account_holder.category` | 账号主体大类：`public_figure`（A1公众人物）、`opinion_leader`（A2意见领袖/KOL/大V）、`institution`（B机构）、`employee`（员工）、`general_public`（普通民众） |
| `account_holder.sub_category` | 账号主体细分类别 |
| `account_holder.identity_verifiable` | 身份是否可独立查证（不仅依赖平台认证） |
| `account_holder.verification_quality` | `high_quality`（高门槛认证）、`low_quality`（低门槛/付费认证）、`unverified`（未认证） |
| `account_holder.verification_relevance_to_claim` | 认证范围与当前言论领域的匹配度 |
| `account_holder.follower_count_tier` | 粉丝量级：`mega`（百万+）、`macro`（十万级）、`mid`（万级）、`micro`（千级）、`nano`（百级以下） |
| `account_holder.professional_domain` | 可查证的专业领域 |
| `stance_analysis` | 立场倾向分析结果 |
| `conflict_of_interest` | 利益关系检测结果 |

如果判定为自媒体，应终止本规则，将 `source_type` 改为 `self_media`，使用 `source_self_media.md` 中的输出格式。
