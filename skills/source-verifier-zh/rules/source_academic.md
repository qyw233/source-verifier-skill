# 学术来源处理规则

学术来源适合支持技术、科学、方法论和实验结论，但需要区分证据强弱。

## 来源强度

### 高强度

```text
同行评审期刊论文
同行评审会议论文
正式出版社页面
DOI 记录
系统综述或 meta-analysis
标准教材或经典专著
```

### 中等强度

```text
arXiv 预印本
大学机构仓库
工作坊论文
技术报告
实验室页面
```

### 较弱

```text
PPT
海报
未发表手稿
无同行评审的博客文章
只在社交平台发布的结论
```

## 检查步骤

1. 提取标题、作者、年份、发表渠道、DOI 或 arXiv ID标。
2. 判断是否同行评审。
3. 检查相关论点（如实验结果、结论）是否在论文中得到充分阐述。
4. 区分作者自己的结论与引用他人的背景描述。
5. 区分实验结果、假设、未来工作和推测。
6. 检查是否有更新版本、勘误或撤稿信息。

## 常见风险

说明研究结论时的限制：

例如：

```text
论文只在仿真中验证 ≠ 已证明真实系统有效
小样本实验有效 ≠ 普遍有效
作者提出方法 ≠ 该方法已成为主流
相关工作中提到 ≠ 本文证明了该结论
预印本结果 ≠ 已经同行评审确认
```

## AI / 控制 / 工程类论文特别注意

检查：

```text
是否有真实实验还是仅仿真
数据集或代码是否公开
对比基线是否充分
是否说明限制条件
实验指标是否充分
是否存在参数调优偏差
```
