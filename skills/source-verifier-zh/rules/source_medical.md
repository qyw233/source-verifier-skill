# 医疗健康信息特殊规则

医疗健康属于高风险领域，必须使用高质量来源，并避免把弱证据包装成诊断或治疗建议。

## 最佳来源

```text
临床指南
政府卫生机构
药品监管机构
医学会
系统综述
meta-analysis
同行评审医学论文
大型医院科普页面
药品说明书
```

## 弱来源

```text
网红健康博主
保健品网站
患者个人故事
论坛经验
营销软文
无资质医疗博客
短视频评论
```

## 必须检查

```text
发布时间或更新日期
是否为指南或综述
是否适用于用户所在地区
是否存在商业利益
是否针对成人、儿童、孕妇等特殊人群
是否只是相关性而非因果性
```

## 输出要求

医疗相关回答应包含：

```text
证据等级
来源日期
是否可能过时
个体诊断需咨询医生
紧急症状需及时就医
```

## 禁止行为

```text
不要用单个病例支持普遍结论
不要用保健品营销页作为中立医学证据
不要从论坛经验推出诊断
不要把相关性说成因果性
不要给出超出证据范围的治疗建议
```

## 证据标签建议

```text
high_quality_guideline
systematic_review
peer_reviewed_study
hospital_education
anecdotal
commercial_content
insufficient_medical_evidence
```
