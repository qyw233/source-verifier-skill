# 争议来源名单

记录信誉存在争议、需格外谨慎对待的网站、实体或社交媒体账号。这些来源的质量不稳定——可能有高质量内容，也可能有误导信息。评估时必须结合具体文章内容独立判断，不能因名单而全盘否定或全盘接受。

## 使用规则

```text
- 本名单为最高优先级判定依据，命中后不再执行步骤 6（来源类型详细规则逐条检查）
- 在开始逐一评估来源之前，先读取本文件及 reputation_trusted.md、reputation_unreliable.md
- 如果来源的域名/实体/URL 命中本名单 → source_reliability_score 直接设为 35-50 分
- citation_usability 直接设为 use_with_caution
- 在 warnings 中注明"该来源在争议名单中，为最高优先级争议判定"
- 争议名单设定的是信任上限——内容可以比上限更好但不会更糟
- 文章质量评分（article_quality_score）仍需独立逐篇评估
- 名单优先级：可靠名单 > 争议名单 > 不可靠名单（同时命中以最高优先级为准）
```

## 格式说明

```text
每行一个条目，格式：类型 | 名称 | 识别条件 | 争议原因
类型: domain（域名）/ url_pattern（URL模式）/ social_account（社交账号）/ entity（实体名称）
名称: 来源的简要名称
识别条件: 域名、URL 模式、或社交账号标识（平台:用户名）
争议原因: 简要说明争议点
```
