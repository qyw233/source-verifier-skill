## Agent 使用方式

1. 从用户提问中提取主题关键词
2. 对照本注册表，匹配所有命中的主题
3. 对每个命中主题，加载对应的规则文件
4. 将主题规则叠加到已有的来源类型规则之上（主题规则是附加约束，不替代来源类型规则）
5. 如果命中多个主题，加载所有对应规则文件，综合评估

## 匹配逻辑

```text
- 用户提问中明确提及某主题关键词 → 确定命中
- 用户提问虽未直接提及关键词，但提问内容实质属于某主题范畴 → 也应命中
  （如用户问"某药能否治疗某病"虽未提"医疗"二字，但实质属医疗健康主题）
- 用户提问不涉及任何已注册主题 → 跳过主题规则叠加步骤
- 用户提问跨多个主题 → 加载全部相关规则
```

## 自定义扩展

**用户可以自行扩展本注册表以适应其专业领域需求。**

### 手动添加

直接在注册表中新增一行，按如下格式填写：

```text
| 主题名称 | 触发关键词（逗号分隔） | `rules/source_xxx.md` |
```

然后在 `rules/` 目录下创建对应的规则文件（参照现有主题规则文件的格式，包含 `source_reliability_score` 调整、`citation_usability` 约束、领域特定警告等）。

### 让 Agent 代劳

也可以直接告诉 Agent 你的需求，例如：

```
"帮我添加一个金融投资主题，覆盖股票、基金、加密货币等内容"
"帮我在主题注册表里增加教育学术领域"
```

Agent 会自动在本注册表中注册新主题，并创建对应的规则文件。

### 注意事项

- 每个主题对应的规则文件名建议使用 `rules/source_<domain>.md` 命名规范
- 规则文件需遵循现有主题规则文件的格式：包含"最佳来源""可用性约束""领域特定警告""不可作为证据的场景"等章节
- 修改注册表后无需修改 SKILL.md——Agent 会自动从注册表中读取主题映射
