# 时效性判断规则

某些信息会快速变化，因此来源是否“新”会直接影响可靠性。

## 一、必须重视时效性的主题

以下主题需要优先使用最新来源：

```text
新闻事件
政治人物和职务
公司 CEO、产品状态、价格、功能
AI 模型、API、开源状态、许可证
软件版本、依赖、系统要求
法律法规、政策、监管规则
医疗指南、药品说明、安全警告
金融价格、汇率、股票、基金
体育比分、赛程、排名
旅行签证、航班、景点开放情况
```

## 二、时效等级

### fresh

来源发布时间适合当前问题，且没有明显过时风险。

### possibly_outdated

来源可能过时，需要寻找更新来源确认。

### outdated

来源明显过时，不应作为当前事实的最终证据。

### timeless

基础概念、数学公式、历史事实、经典论文等通常不需要最新来源，但仍要注意版本差异。

## 三、不同领域的粗略判断

```text
AI / 软件功能：优先 30–90 天内来源；官方文档以当前版本为准。
新闻事件：优先最近几天到几周来源。
政策法规：优先当前有效文本，检查生效日期和修订日期。
医疗建议：优先近年指南、系统综述、监管机构更新。
学术基础理论：经典来源可用，但前沿结论需近期文献。
```

## 四、处理规则

1. 如果来源无日期，应加 `no_date` 警告。
2. 如果来源日期早于已知关键变更点，应评估其结论是否依然有效。
3. 如果官方文档有更新版本，应优先使用更新版本。
4. 对“最新”“最近”“现在是否支持”等问题，必须查找当前来源。
5. 如果只有旧来源，应输出“不确定”或“可能已过时”。

## 五、输出字段建议

```json
{
  "freshness": "fresh | possibly_outdated | outdated | timeless",
  "published_at": "2026-04-12",
  "updated_at": "2026-04-20",
  "freshness_note": "该来源为官方 release note，且发布时间非常接近。"
}
```
