# 可疑来源处理规则

当来源存在严重风险时，应标记为可疑来源，默认不作为最终证据。

## 可疑信号

```text
无作者
无日期
无机构信息
无联系方式
内容疑似复制
大量广告或跳转
标题明显夸张
域名伪装官方
页面充满关键词堆砌
没有出站链接
引用链断裂
内容与标题不符
疑似 AI 生成垃圾内容
```

## 处理方式

默认：

```text
citation_usability: do_not_use
```

例外：

该来源可以作为线索，用来寻找更好的原始来源。

## 必须执行

遇到可疑来源时：

1. 不要直接引用它作为证据。
2. 尝试寻找它所复制或转述的原始来源。
3. 检查内容是否出现在更可靠网站。
4. 如果找不到更可靠来源，应标记为证据不足。

## 输出建议

```json
{
  "source_type": "suspicious",
  "citation_usability": "do_not_use",
  "warnings": [
    "无作者和日期",
    "疑似采集站",
    "未提供原始来源"
  ],
  "recommended_action": "search_for_primary_source"
}
```
