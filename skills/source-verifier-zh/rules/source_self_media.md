# 自媒体来源处理规则

自媒体指个人或小团队以独立创作者身份在社交/内容平台上运营的账号，通常依赖平台流量分成、广告、带货或知识付费变现。与官方账号和传统媒体的核心区别在于：缺乏机构编辑审核机制，内容质量完全取决于个人能力与动机。

**默认可信度假定：自媒体来源整体可信度较低，默认不高于 `use_with_caution`。** 即使是专业型自媒体，也必须经过严格的内容质量验证才能有限度引用。不能因为自媒体数量多、说法一致就放松判断——恰恰相反，大量自媒体重复同一说法往往说明该说法已在洗稿/搬运链条中被病毒式传播，而非经过多方独立验证，此时应格外警惕。

**自媒体不能作为唯一证据，一般需要其他独立来源交叉验证。**

### 例外：当用户查询直接针对该自媒体本身时

若用户的提问就是关于该自媒体的自身情况、观点、言论或状态（例如"某自媒体是怎么评价XX事件的""某博主对XX产品的看法是什么""某自媒体发布过什么内容"），则该自媒体的内容对于回答该问题而言属于**一手原始来源**：

```text
触发条件（满足任一即可）：
  - 用户明确询问该自媒体的观点、态度、言论
  - 用户询问该自媒体的自身情况（如运营状态、商业合作、争议事件等）
  - 用户询问该自媒体是否发表过某类内容
  - 用户以该自媒体为研究对象或信息目标

此时的处理方式：
  → source_type 升级为 official，添加次级标签 primary_source
  → 该自媒体对于"它说了什么""它的观点是什么"具有最高证据效力，视为官方一手消息
  → citation_usability 可提升至 highly_usable
  → 在 reasons 中注明"用户查询直接针对该自媒体，其自身内容属官方一手来源"

重要边界：
  - 该自媒体对其自身言论/观点是一手来源，但对其言论中涉及的外部事实仍需独立验证
  - 例：用户问"某自媒体对XX事件的评价" → 该自媒体内容是一手来源，可用
  - 例：用户问"XX事件是否属实"，引用了某自媒体的说法 → 该自媒体仅是二手来源，不可作为唯一证据
  - 判断标准：用户提问的答案主体是该自媒体本身，还是该自媒体所谈论的外部事实
```

## 一、自媒体类型细分

### 1. 专业型自媒体

由具备领域专业背景的个人运营（如注册医师、执业律师、高校教师、行业工程师实名认证），内容以专业知识普及为主。

```text
特征：实名、可查证的专业资质、内容严谨、有引用来源
信任等级：C，个别可达 B
```

### 2. 经验型自媒体

由从业者或亲历者运营，内容以行业经验、操作技巧、踩坑记录为主。

```text
特征：第一人称经验描述、可复现、有具体场景
信任等级：C 或 D
```

### 3. 营销型自媒体

以商业变现为主要目的，内容围绕带货、课程推广、品牌合作、流量变现。

```text
特征：商业链接密集、标题夸张、内容浅薄、频繁推销
信任等级：D 或 E
```

### 4. 搬运/洗稿型自媒体

大量复制、拼接、翻译他人内容，缺乏原创信息。

```text
特征：内容高度雷同他人、无一手信息、无作者观点
信任等级：E
```

### 5. 情绪/流量型自媒体

以煽动情绪、制造争议、蹭热点为主要手段获取流量。

```text
特征：标题党、二元对立叙事、缺乏数据支撑、评论区情绪化
信任等级：E
```

## 二、质量评估信号

### 正面信号

```text
作者身份可查证，具备相关领域资质或从业背景
内容引用官方来源、论文、法规原文，并提供可追溯链接
数据有出处，方法有说明，结论有边界
区分事实陈述与个人观点
内容长期一致，历史记录无反复打脸
评论区存在有质量的讨论和作者补充
作者对错误内容有更正记录
无隐藏商业利益（或已明确标注赞助/合作）
```

### 负面信号

```text
作者身份模糊或不可查证
频繁使用"据说""网传""知情人士""内部消息"而不给来源
历史内容多次被证伪或与事实矛盾
标题与正文严重不符
内容以情绪驱动而非事实驱动
商业推广未标注
跨平台发布大量同质化内容
评论区控评、删评或只有粉丝刷赞
通过制造焦虑、恐惧促成转化（如"再不XX就晚了"）
```

## 三、不同场景的使用规则

**默认前提：自媒体来源在所有场景下，默认 citation_usability 不超过 `use_with_caution`。以下"可以谨慎使用"的场景是该默认上限下的例外允许，并非将自媒体提升为可靠来源。**

### 可以谨慎使用

```text
作者为实名且具有可查证专业背景的领域知识科普
具体可复现的操作教程、配置方法、排错经验
特定产品的真实使用体验（需标注为个人体验）
行业从业者的趋势观察（需明确是个人观点）
```

使用时必须：
- 标注为"个人观点/经验，未经独立验证"
- 如果存在更权威来源，优先使用权威来源
- 不将该来源作为唯一证据

### 不可作为证据

```text
医学诊断、治疗建议
法律意见、政策解读作为唯一依据
金融投资建议
科学结论或统计数据的唯一来源
公司运营状态、产品发布的唯一确认
开源许可证判断的唯一依据
重大新闻事件的唯一报道
```

### 多自媒体重复 ≠ 多方验证

**核心原则：自媒体来源的数量不能替代质量。多个自媒体重复同一说法，不等于该说法已得到多方验证。**

当评估多个来源时，如果发现多个中文自媒体账号重复同一说法，必须应用以下规则：

```text
1. 首先判断该说法是否有官方来源或权威一手来源印证：
   - 有官方/一手来源 → 以官方/一手来源为准，自媒体仅作补充
   - 无官方/一手来源 → 进入步骤 2

2. 判断是否有高信誉新闻媒体独立报道：
   - 有高信誉媒体具名报道且引用原始来源 → 可部分参考媒体判断
   - 仅有质量一般的媒体或未具名报道 → 等同于无独立验证，进入步骤 3
   - 无任何媒体独立报道 → 进入步骤 3

3. 仅有自媒体互相重复：
   → 不视为多方独立验证
   → 整体证据等级：evidence_insufficient
   → 结论：该说法缺乏可靠来源支持，不能作为任何事实依据
```

#### 典型危险信号

```text
- 同一话题被大量中文自媒体账号密集发布，但内容高度相似
- 这些自媒体均未提供可追溯的原始来源链接
- 追溯到的最早来源仍是另一个自媒体账号
- 无英文/原产地语言的一手来源印证
- 无官方公告、无论文、无法规原文、无数据源头
- "外媒报道""据透露""知情人士称"等模糊引用链
```

#### 涉及中文生态环境特别说明

中文自媒体生态中大量以流量为导向的内容生产：
```text
- 一个未经证实的说法可能在数小时内被数十个自媒体账号改写传播
- 这种"数量多"是洗稿/搬运的结果，而非多方独立调查的结果
- 即使来源数量达到几十个，其证据强度仍然为零
- 对这种情况应格外警惕，绝不能因为"多个来源一致"而提高可信度评估
- 此时应主动搜索原产地语言的官方或权威来源重新核验
```

#### 判定输出

```text
- 单个自媒体来源的 citation_usability 不变（仍按原有规则评估）
- 但在冲突解决层面，多个自媒体的"一致"不算独立验证
- 冲突状态标记：evidence_insufficient
- 必须输出警告："多个中文自媒体重复同一说法，但均未追溯到官方或权威一手来源，不视为有效印证"
- 建议动作：search_for_origin_language_primary_source
```

## 四、不同领域的特殊规则

### 医疗健康

自媒体发布的医学内容：
```text
执业医师实名认证 + 引用指南/论文 → use_with_caution（仍需标注非诊疗建议）
无资质或不可查证 → do_not_use
即使作者是医生，个体建议 ≠ 诊疗标准
```

### 法律政策

```text
执业律师实名 + 引用法条原文 → use_with_caution（需标注非法定法律意见）
无资质 → do_not_use
不应将自媒体解读等同于法规本身
```

### 金融投资

```text
无论作者资质如何，自媒体金融建议默认 not_recommended
可参考作者提供的数据，但不应单独作为投资决策依据
需检查是否存在利益相关（如持仓披露）
```

### AI / 科技

```text
行业从业者可实现经验、技术教程 → 可参考
开源状态、API 功能、模型能力 → 必须交叉验证官方来源
产品评测、性能对比 → 需检查是否有商业合作
```

## 五、跨平台矩阵评估

如果同一自媒体在多个平台运营（如同时有公众号、B站、抖音、小红书等），应：

```text
1. 检查各平台内容是否一致
2. 不同平台可能有不同内容策略（如深度内容在公众号，引流内容在抖音）
3. 关注内容质量最高的平台作为主要参考
4. 矩阵化运营本身不是负面信号，但需关注是否有组织化营销行为
```

## 七、快速判断流程图

```text
社交平台账号
  │
  ├─ 是否为机构/组织认证？ → 是 → official_social → 按 source_social.md 官方规则
  │
  └─ 否 → 是否以个人身份运营？
          │
          ├─ 是否具备可查证专业资质 + 无商业变现 + 引用原始来源？
          │   └─ 是 → 专业型自媒体 → 可谨慎引用，上限 use_with_caution
          │
          ├─ 是否有商业变现、标题党、情绪化、内容浅薄中任一特征？
          │   └─ 是 → 根据严重程度定为 not_recommended 或 do_not_use
          │
          └─ 是否为搬运/洗稿/无原创？
              └─ 是 → do_not_use，建议寻找原始来源

注意：无论评估结果如何，自媒体来源默认不可作为事实的唯一依据。
多个自媒体来源说法一致 ≠ 多方验证，反而应视为洗稿/搬运链条的警示信号。
```
