# 通用评分规则

每个来源需要给出四类结果：

1. `source_reliability_score`：信源整体可靠性
2. `article_quality_score`：当前文章或页面质量
3. `citation_usability`：是否适合作为最终引用

## 一、信源可靠性评分 source_reliability_score

从 50 分开始。

### 加分项

```text
官方来源：+35
政府、法律、监管机构来源：+35
官方文档、release note、项目仓库：+30
同行评审学术论文：+30
预印本或大学机构页面：+20
高信誉新闻机构：+20
专业机构或研究机构：+15
作者和机构清晰：+8
有更正机制或编辑规范：+5
页面链接到原始来源：+8
```

### 扣分项

```text
普通社交平台内容：-20
匿名博客：-15
无作者：-8
无日期：-8
未链接原始来源：-10
采集站、镜像站、SEO 内容农场：-35
标题明显夸张或误导：-20
命中已知低可信来源名单：-40
只引用其他二手来源：-10
疑似广告或赞助但未标注：-20
```

分数限制在 0 到 100 之间。

## 二、文章质量评分 article_quality_score

评估具体页面，而不是只看域名。

### 正面信号

```text
有明确作者
有发布时间或更新时间
有原始来源链接
有数据、代码、论文、公告或法规原文
有直接引用或可追溯证据
明确区分新闻、评论、广告、赞助内容
标题与正文一致
```

### 负面信号

```text
无作者
无日期
无原始来源链接
标题党
大量使用“据说”“网传”“外媒称”“有消息称”
正文和标题不一致
疑似复制其他站点内容
过度 SEO 化
广告或营销内容过多
```

## 三、引用可用性 citation_usability

引用可用性不等同于信源可靠性。必须结合“文章内容质量”和“与用户提问的相关度”进行判断。

### highly_usable

满足：

```text
来源为原始来源或高质量权威来源
充分且直接回答了用户的问题
文章质量极高，有充分证据
没有明显时效或上下文问题
可追溯、可打开、可核验
```

### usable

满足：

```text
来源整体可靠
能够部分或间接回答用户问题
文章质量较好
内容逻辑自洽，有参考价值
可能是二手来源，但链接或引用了原始来源
```

### use_with_caution

满足任一：

```text
内容不完整或存在偏差
勉强与用户问题相关，但不直接
来源是二手报道
存在时效风险
缺少作者或原始链接
适合作为补充，而非唯一证据
```

### not_recommended

满足任一：

```text
来源质量较低
关键事实描述模糊
虽然来源可靠，但与用户提问不相关或回答毫无用处
缺少关键上下文
只有传言或转述
已有更好来源可用
```

### do_not_use

满足任一：

```text
采集站、垃圾站、伪官方站
内容严重误导
来源无法访问或内容不完整
与高可信来源矛盾
用于高风险主题但证据不足
```

## 四、输出要求

不要只输出分数，必须输出原因。

推荐格式：

```json
{
  "source_reliability_score": 82,
  "article_quality_score": 76,
  "citation_usability": "usable",
  "reasons": [
    "该来源为官方文档",
    "页面包含发布时间和明确功能说明",
    "内容详细且逻辑自洽"
  ],
  "warnings": [
    "没有独立第三方验证性能结论"
  ]
}
```
