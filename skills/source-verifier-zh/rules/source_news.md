# 新闻媒体处理规则

新闻媒体适合核实事件、公告、采访和公共说法，但大多数新闻属于二手来源。评估新闻来源时，需要先溯源到原始报道媒体，再对该媒体的权威度、立场和文章质量进行综合判断。

## 一、首先判断是否为转载/聚合

拿到一篇新闻报道后，第一步是确认它是否为原始报道。大量新闻网站实际上是转载或聚合其他媒体的内容，直接引用转载站点会丢失对原始媒体的溯源。

### 转载/聚合识别信号

```text
文章开头或末尾标注"来源：XXX""转自：XXX""Via：XXX"
文章内有"据XX报道""XX社消息"但未链接原文
页面域名明显不是新闻机构（如 SEO 聚合站、内容农场）
同一篇文章出现在多个域名下，内容几乎完全相同
文章作者为"编辑整理""综合报道"而非具名记者
域名类似知名媒体但略有差异（仿冒或镜像站）
```

### 溯源处理

如果判定为转载或聚合，必须按以下步骤处理：

```text
1. 从文中提取原始来源线索（媒体名、记者名、原文链接）
2. 通过搜索引擎或原文链接找到该报道的原始发布页面
3. 核实原始页面是否真实存在、内容是否一致
4. 将评估对象切换为原始媒体，而非当前转载站点
5. 对转载/聚合站点标次级标签 secondary_report 或 aggregator_or_scraper

如果无法找到原始来源：
  → 标记 "原始来源不可追溯"
  → citation_usability 降一级
  → 如有多个转载站点但无一可追溯，不可视为独立验证
```

## 二、评估媒体的权威度

找到原始报道媒体后，需要对该媒体的整体权威度进行评估。注意：同一媒体在不同领域权威度可能截然不同。

### 2.0 媒体权威度三级分类

在按领域评估之前，先将媒体按机构性质和审核机制分为三个等级：

#### 第一级：高权威媒体

官方通讯社及传统纸媒/广播/电视的网站：
```text
- 官方通讯社：新华社、Reuters、AP、AFP、TASS 等
- 传统纸媒网站：人民日报、光明日报、NYT、Washington Post、WSJ、The Guardian、The Telegraph、财新、第一财经等
- 传统广播/电视机构网站：BBC、CNN、CCTV、NHK 等

特征：有线下纸媒或广播传统，存在严格的多层编辑审核机制，有公开的更正政策
信任基线：高
英文传统媒体（如 NYT、BBC、The Guardian、Reuters、AP 等）经过长期发展的编辑审核体系，通常有较高的可信度基线——但这不代表无需核实，仍需检查具名记者和原始来源引用。
```

#### 第二级：中等权威媒体

较小媒体及纯数字新兴媒体：
```text
- 纯数字原生媒体（无纸媒传统）：36氪、虎嗅、品玩、界面新闻、TechCrunch、The Verge、BuzzFeed News 等
- 地方性小媒体
- 行业垂直媒体（如科技、汽车、游戏等垂直领域媒体）

特征：无传统纸媒的严格多层审核机制，内容发布速度往往优先于准确性，编辑流程相对简化
信任基线：中
风险提示：第二级媒体与第一级媒体的核心区别在于审核流程的严格程度，其报道不能自动等同于高权威来源，需结合文章质量独立评估。
```

#### 第三级：低权威媒体/类自媒体

带有媒体外衣但实质上接近自媒体的来源：
```text
- 内容聚合平台上的"媒体号"
- 以流量为主要目的、编辑规范缺失的"新媒体"
- 无明确编辑团队的所谓"新闻网站"

特征：缺乏可查证的编辑团队和审核流程，内容以流量为导向
信任基线：低，评估时应参照 self_media 或 aggregator_or_scraper 规则
```

#### 分级使用规则

```text
第一级媒体 + 具名记者 + 引用原始来源 → 可独立作为可靠引用，citation_usability 可到 highly_usable
第一级媒体 + 匿名消息源 → citation_usability 不超过 usable（见"匿名消息源特别规则"）
第二级媒体 + 具名记者 + 引用原始来源 → usable，但建议交叉验证
第二级媒体 + 未具名/未引用原始来源 → use_with_caution
第二级媒体与自媒体/博客论坛说法一致，但无第一级或官方来源印证 → 不视为有效多方验证（详见 5.2.1）
第三级媒体 → 按 blog_forum 或 self_media 规则评估
```

### 2.1 按领域评估

媒体的权威度不是绝对的，必须结合用户问题的领域进行判断：

```text
科技/互联网：
  高权威：The Verge、Ars Technica、Wired、InfoQ
  中等：TechCrunch、36氪、机器之心
  注意：科技媒体对技术细节的描述可能出现偏差，不宜替代官方文档

财经/商业：
  高权威：Reuters、Bloomberg、Financial Times、财新、第一财经
  中等：华尔街见闻、雪球
  注意：财经媒体对上市公司报道可能有市场影响动机

政治/国际关系：
  高权威：Reuters、AP、BBC、新华社
  中等：各国主流官方媒体
  注意：政治报道受媒体立场影响最大，见下文 2.2

科学/医学：
  高权威：Nature News、Science News、STAT News
  中等：一般科技媒体的科学板块
  注意：科学新闻常夸大论文结论，需对照原始论文
```

在评估时，应基于自身知识或通过网络调研，判断该媒体在用户问题所处领域是否具有公认的权威性。如果一个媒体在领域 A 是顶级，但在领域 B 只是普通水平，需要据此调整分数。

### 2.2 政治立场与媒体倾向

不同国家、同一国家不同媒体的政治立场天然不同，部分报道可能在事实选取、措辞、篇幅上体现倾向性。

#### 需要特别关注立场的情况

```text
用户问题涉及国际关系、领土、主权、民族、宗教等敏感话题
用户问题涉及不同国家/地区的政策对比
报道对象为某国政府、政党或政治人物
报道涉及正在发生的地缘冲突或争议事件
报道明确包含褒贬评价、价值判断
```

#### 常见媒体立场参照

```text
不同国家的官方/半官方媒体天然代表各自国家立场：
例如
  中国：新华社、人民日报、CGTN
  美国：CNN、Fox News、MSNBC、NYT
  英国：BBC、The Guardian、The Telegraph
  俄罗斯：RT、TASS
  卡塔尔：Al Jazeera

同一国家内不同媒体有不同倾向：
例如
  美国左倾/自由派：NYT、CNN、MSNBC、Washington Post
  美国右倾/保守派：Fox News、NY Post、Wall Street Journal（评论版）
  英国左倾：The Guardian
  英国右倾：The Telegraph、Daily Mail
```

#### 处理方式

```text
一般情况下（用户未特殊要求）：
  如果用户问题不涉及政治敏感话题 → 仅作为背景参考，不影响主体评分
  如果用户问题涉及政治敏感话题 → 必须标注该媒体的立场倾向
    → 建议补充不同立场来源进行交叉验证
    → 在 warnings 中注明"该媒体存在特定政治倾向"

用户明确要求核查立场时：
  → 尽可能核查并输出该媒体的政治倾向、股东背景、编辑方针
  → 如果涉及具体记者，核查该记者过往报道的倾向性
  → 在报告中增加 media_stance 字段
```

### 2.3 媒体信誉评估

综合评估该媒体的整体信誉，包括但不限于：

```text
正面信号：
  有公开的编辑规范和更正机制
  有明确的新闻/评论/赞助内容区分
  有记者署名和编辑联系方式
  历史上重大事件报道准确
  获得新闻行业奖项或认证
  被其他高信誉媒体引用

负面信号：
  曾因虚假报道被证伪或起诉
  标题党现象严重
  新闻与广告边界模糊（软文、原生广告未标注）
  存在明显的政治或商业利益驱动
  历史上传播过阴谋论或伪科学
  撤销报道不公开解释
```

## 三、文章层面质量评估

即使媒体整体权威度较高，具体文章质量仍需独立评估。

### 正面信号

```text
有具名记者，可查证其过往报道记录
有明确的发布时间和更新时间
引用并链接到原始来源（官方公告、论文、文件）
有具名消息源（非"知情人士"）
有官方回应或多方采访
区分新闻报道与记者评论
数据有来源说明和方法论
```

### 负面信号（红旗）

```text
"据网传""有消息称""外媒报道"但不放具体媒体名或链接
"知情人士透露"但不提供任何背景
无作者署名
无发布日期
标题与正文严重不符
大量复制其他媒体内容，无独立采编
明显营销软文（产品推广伪装成新闻）
匿名消息源为唯一消息源且内容敏感
 情绪化用词、煽动性标题
```

### 匿名消息源特别规则

当报道使用匿名/模糊信源表述时，无论媒体等级如何，均须降权处理：

#### 匿名信源表述（中文）

```text
"消息人士称""知情人士透露""内部人士表示""接近...的人士"
"据透露""不愿具名的官员/高管""业内人士"
"据...内部人士" 等
```

#### 匿名信源表述（英文）

```text
"people familiar with the matter""sources say""industry sources"
"a person close to...""an official speaking on condition of anonymity"
"according to sources""it is understood that" 等
```

#### 降权规则

```text
- 单一匿名消息源且无可验证证据 → citation_usability 降一档
- 多个匿名消息源但无任何具名来源印证 → 仍须降权，在 warnings 中注明
- 即使是第一级高权威媒体，仅靠匿名消息源的报道也不能等同于该媒体具名报道的可信度
- 匿名消息源报道 + 无其他独立来源印证 → citation_usability 不超过 use_with_caution
```

#### 注意

```text
- 匿名消息源在调查报道中是合法且必要的新闻手段，本规则不否定其新闻价值
- 但在信源核实场景中，匿名消息源无法追溯验证，证据强度天然较弱
- 不应将基于匿名消息源的报道视为"已确认事实"或"官方立场"
- 若多个媒体均引用同一匿名消息源（如"据知情人士"且内容一致），不应视为多家独立验证——那只是同一消息源的多家转发
```

## 四、作者/记者立场核查（按需）

一般情况下不需要核查具体记者的立场。仅在以下情况触发：

```text
用户明确要求核查记者立场
报道内容高度争议且用户关注信息可信度
记者名气极大且其个人立场明显影响报道
```

核查内容（如触发）：

```text
记者的工作履历和所属媒体
记者过往报道的主题倾向
记者公开发表的政治或行业观点
记者社交媒体上的表态（如涉及报道主题）
记者是否与报道对象存在利益关系
```

## 五、多来源使用规则

### 5.1 突发新闻

```text
要求至少 2-3 个独立高信誉媒体互相印证
优先选择有现场记者或官方确认的来源
注意：同一集团的多个媒体（如同一母公司旗下）不能视为独立来源
```

### 5.2 多来源重复

```text
如果多家媒体内容高度相似但不给原始来源链接：
  → 可能只是互相转载或改写
  → 不能视为独立验证
  → 应寻找最早发布时间且带有最详细原文引用的那篇，溯源到原始媒体
```

### 5.2.1 不同权威度来源混合印证规则

当第二级媒体与自媒体、博客论坛等更低权威度来源说法一致时：

```text
核心原则：第二级媒体的审核标准本身较宽松，无法为更低权威度的来源提供权威背书。

规则：
- 仅有第二级媒体 + 自媒体/博客论坛一致 ≠ 有效多方验证
- 这种"一致"不提高整体可信度
- 必须追溯是否有第一级媒体或官方来源独立确认同一说法
- 如果没有第一级或官方来源印证 → 整体证据等级仍为 evidence_insufficient
- 在 warnings 中注明："仅有第二级媒体和自媒体来源一致，未经高权威来源独立印证"
- 应格外警惕，不能因为"看起来多方报道了"就放松判断
```

### 5.3 新闻可以用于与不可用于

```text
可以用于：
  事件发生时间、地点、参与方
  公司公开声明、财报数据
  采访中当事人直接引语
  新闻背景、社会反应

不宜单独用于：
  技术功能细节 → 优先官方文档
  开源许可证判断 → 优先仓库的 LICENSE 文件
  医学结论 → 优先同行评审论文或监管机构
  法律结论 → 优先法规原文
  科学共识 → 优先综述论文或学术机构声明
  性能领先结论 → 需要独立评测
```

## 六、输出建议

```json
{
  "source_type": "news",
  "article_type": "news | opinion | analysis | sponsored | press_release_repost | breaking",
  "is_repost": false,
  "original_media": {
    "name": "Reuters",
    "url": "https://www.reuters.com/...",
    "verified": true
  },
  "media_authority_by_field": {
    "relevant_field": "technology | finance | politics | science | general",
    "authority_level": "high | medium | low | unknown"
  },
  "media_stance": {
    "political_leaning": "left | center_left | center | center_right | right | varies | not_applicable",
    "country_of_origin": "CN | US | UK | ...",
    "note": "该媒体来自美国，在中美关系议题上可能存在立场倾向"
  },
  "media_credibility": "high | medium | low | disputed",
  "media_tier": "tier_1 | tier_2 | tier_3",
  "anonymous_sources_only": false,
  "links_to_primary_source": true,
  "multiple_independent_sources": false,
  "citation_usability": "highly_usable | usable | use_with_caution | not_recommended | do_not_use",
  "reasons": [
    "转载自 Reuters 原始报道",
    "Reuters 在国际财经领域权威度较高",
    "文章引用了官方公告原文"
  ],
  "warnings": [
    "该媒体在政治类议题上存在特定立场倾向",
    "建议补充不同立场来源进行交叉验证",
    "技术细节部分未提供原始来源"
  ]
}
```

### 新增字段说明

| 字段 | 说明 |
|------|------|
| `is_repost` | 是否为转载/聚合，非原始报道 |
| `original_media` | 原始媒体信息（转载时填写） |
| `media_authority_by_field` | 该媒体在用户问题领域的权威度 |
| `media_stance` | 媒体政治倾向与所属国家（涉及敏感议题时必填，一般情况填 `not_applicable`） |
| `media_credibility` | 媒体整体信誉评级 |
| `media_tier` | 媒体权威度分级：`tier_1`（官媒/传统纸媒）、`tier_2`（较小/新兴数字媒体）、`tier_3`（低权威/类自媒体） |
| `anonymous_sources_only` | 报道是否仅依赖匿名消息源 |
| `multiple_independent_sources` | 是否有多个独立来源印证 |
